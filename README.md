# 안세영 — 기록의 코트 / THE SE YOUNG ARCHIVE

실제 3D 코트에서 시작해 경기 결과와 유튜브 영상을 탐색하는 배드민턴 데이터 박물관입니다.

## 실행

Node.js 22 이상, Chrome을 권장합니다.

```powershell
npm ci
npm run dev
npm test
npm run build
npm run test:ui
```

`dist/`를 정적으로 배포합니다. 유료 API·LLM·운영 서버가 필요하지 않습니다.

## 이번 업데이트

- Three.js WebGL 3D 코트·네트·셔틀콕·조명·좌석. 드래그 회전, 시점 초기화, 애니메이션 재생/정지, 2D 전환. WebGL 미지원 환경의 2D 대체 화면.
- 안세영 경기 결과 **402건** 기본 탑재. 파일 업로드 없이 검색, 시즌·승패·패턴·상대·영상 필터, 20/50/100경기 및 전체 보기.
- **68경기·공식 영상 69개** 직접 연결. 모든 수록 경기에는 확인된 영상 또는 해당 경기의 YouTube 검색 링크. 전체 경기/하이라이트 구분, CSV에도 영상 링크 포함.
- GOAT LAB의 15명 직접 비교·연령별 그래프·3시즌 전성기·가중치·히트맵 유지.
- 데이터 방법론 독립 메뉴 제거. 하단 ‘기록 기준 · 출처’에 기본 접힘 상태로 축소.
- QF(8강)를 예선으로 오인해 제외하던 정제 오류 수정. 실제 예선만 별도 판별하며, 경기표에는 예선도 포함.

## 기록의 범위

수록 기간은 **2018-09-04–2026-10-25**입니다. 확보한 경기 결과 전체를 표시하지만 안세영의 전체 커리어 수집이 완료된 것은 아닙니다. 점수 미완결 10건은 경기표에 표시하되 승률·연승에서 제외합니다. 수록 완료 365경기 315승 50패는 이 표본에 대한 값으로, 공식 통산 전적과 구분합니다.

원본 전체 CSV와 다른 모든 선수의 경기 행을 그대로 배포하지 않습니다. 안세영의 날짜·대회·상대·승패·점수 사실을 정규화한 결과와 파생 집계를 제공합니다. 출처는 경기별 링크와 접힌 영역에 남깁니다. 원본: SahilMotyar/bwf-match-data, BWF 대회 결과. 별도 검증 6경기는 OCA·프랑스오픈 조직위·검증 가능한 보도 근거입니다. 미확보 경기나 영상 ID를 생성하지 않습니다.

GOAT 업적 공통 기준은 2024-12-31, 연령 비교는 2026-10-27까지 확인한 날짜를 사용합니다. 올림픽 기회 없음·무실적 0·자료 미확보는 구분합니다. 세계 1위 누적은 9명, 경기 전 랭킹과 연구 Elo는 Harvard 원자료를 연결했습니다. 결측값을 0이나 현재 랭킹으로 채우지 않습니다. 전성기는 2018–2024 동일 등급 범위의 최소 20경기 이상 연속 3시즌 창에서 계산합니다. 가중치 공식은 접힌 비교 기준과 실험실 내부에서 확인할 수 있습니다.

## 데이터 갱신

```powershell
npm run data:research
npm run data:build
npm run data:videos
node scripts/collect-videos.mjs --more
npm run data:build
npm test
npm run build
```

`data:research`는 원본을 비배포 `.research/`에 보관합니다. `data:build`는 `data/`의 검증 기록과 원자료에서 정적 JSON을 만듭니다. 새 수집 없이 기존 배포본을 실행하려면 데이터 생성 단계 없이 설치·빌드만 하면 됩니다.

영상 수집은 공개 YouTube 검색과 oEmbed를 사용합니다. BWF TV 공식 채널·제목·대회·연도·라운드·두 선수가 모두 확인되고 경기 하나로 유일하게 연결될 때만 직접 영상을 등록합니다. 검색 실패·지역 제한·영상 삭제 가능성은 있으며 확인되지 않은 영상은 검색 링크로 남깁니다. 영상 파일·방송 이미지를 복제하지 않습니다.

주요 파일: `src/Court3D.tsx`, `src/engine.mjs`, `src/videos.mjs`, `data/videos.json`, `data/verified-matches.json`, `scripts/build-data.mjs`, `scripts/collect-videos.mjs`. 결과는 `src/archive.json`과 `public/data/archive.json`에 생성합니다.

## 배포와 자동 갱신

GitHub Pages: 이 폴더를 저장소 루트로 올리고 Settings → Pages → GitHub Actions를 선택합니다. `pages.yml`이 dist를 배포합니다. Vercel: Vite, build `npm run build`, output `dist`, Node 22를 지정합니다. 상대 base와 URL 쿼리 방식으로 하위 경로에서도 동작합니다.

`refresh.yml`은 매주 월요일 한국 시간 11:20에 공개 원자료를 갱신하고 테스트·빌드 후 정적 JSON만 커밋하는 템플릿입니다. 실제 GitHub 저장소 스케줄은 별도 활성화가 필요합니다. 수기 업적·새로운 영상 ID를 자동 추정하지 않습니다. `.openai/hosting.json`은 기존 비공개 Sites 식별자이며 다른 호스팅에서 실행할 때는 필요하지 않습니다.

## 검증과 기존 소스

단위 테스트·Chrome PC/모바일 테스트와 화면 캡처 검토를 수행했습니다. WebGL 렌더링·드래그 회전·2D/3D 전환·전체 402경기·영상 필터·다운로드·모달·기본 접힘을 검사합니다. 자세한 결과는 `qa/REPORT.md`를 참조하세요. 3D는 지연 로딩하여 기록 화면에서 불필요하게 내려받지 않습니다.

최초 전달된 폴더에서는 기존 안세영 index.html과 README를 식별하지 못해 다른 프로젝트를 보존하고 이 독립 폴더에 구현했습니다. 실제 모바일 기기와 Safari·Firefox는 미검증입니다.

## 사진 전시와 가독성 개선

사용자가 제공한 원본 사진 4장을 `public/photos/`에서 정적으로 제공합니다. 메인 스매시 사진, 세 장의 전시 카드, 커리어 사진과 키보드로 조작하는 확대 보기를 추가했습니다. 본문·메뉴·경기표·입력창의 글씨와 터치 영역을 키웠습니다. 유리 질감, 스크롤 등장, 카드 호버 조명, 사진 패럴랙스는 CSS와 브라우저 이벤트로 구현하며 동작 줄이기 설정을 존중합니다. 모바일 그래프와 경기표는 영역 안에서 가로 스크롤합니다. 사진 추가로 기존 3D 코트는 메인 아래의 독립 전시 영역으로 이동했습니다.

2026-10-29 추가 수정: 요청에 따라 '기록 너머의 순간들.' 사진 전시를 메인과 커리어에서 제거했습니다. 메인 스매시 사진과 커리어 대표 사진은 유지합니다.

## 2026-10-29 원자료 확대와 랭킹 그래프

연구 원본의 실제 저장소는 Harvard Dataverse DOI **10.7910/DVN/RSAYV5**, version3, CC BY4.0입니다. 논문 DOI와 데이터 DOI가 달라 이전의 광범위 검색으로 놓쳤으며, 정확한 제목 필드 검색으로 찾았습니다. 세 XLSX의 게시 MD5와 내려받은 파일을 대조했습니다. 전체178,896행 중 여자단식70,306행을 검토하고 비교선수11명이 포함된4,336경기만 정규화했습니다. 경기 전 BWF 랭킹과 연구자가 계산한 Elo를 확보했습니다. Elo는 공식 BWF 점수가 아닙니다.

최종 안세영 수록 결과 **402건**, 점수가 완결된 통계 표본 **390경기**입니다. 기존375건에 단순 덧셈하지 않았습니다. 선수ID·성별과529개 이름 표기를 대조하고 성/이름 순서, 대회 스폰서명, 지연 개최 연도, 예선·조별리그 라운드 표기를 조정했습니다. 학술 자료와 공개CSV 사이3,855건 중복을 병합했으며, 완전 스코어 충돌은 격리합니다(이번 최종 병합0건). 같은 해 태국오픈2개 대회는 개최일이 달라 분리합니다. 날짜1일 차이1건은 원자료 날짜를 채택하고 대체 날짜를 감사 자료에 남깁니다. 통산 수집 완료나 공식 통산 승률을 주장하지 않습니다.

메인 화면에 안세영 랭킹 그래프를 추가했습니다. **478관측값**은 경기 전 순위360건, 공개 수집표106개, 연말·이정표12개로 구성됩니다. 순위/랭킹포인트, 기간 전환, 마우스·키보드·모바일 선택, 출처 확인과CSV다운로드를 지원합니다. 연말 기준일·경기일·수집일은 공식 발표일로 바꾸지 않습니다. 주별 수집표가15일 이상 비거나 경기 관측이30일 이상 비는 곳은 연결하지 않습니다. SanderP99 MIT 데이터의 고정 커밋과 각파일SHA256을 기록했습니다.

전성기 표의 Top10 상대 승패와2018–2024 상대 수준 가중치를 원자료의 **경기 전 상대 BWF 랭킹**으로 계산합니다. 현재 순위나 뒤에 수집된 표를 소급하지 않습니다. 점수 조건은 완료20경기,Top10상대10경기,상대랭킹 확보율90%이상입니다. 5개 지표 실험의 적격선수는7명입니다. 과거 선수의 3시즌 표본도 중복을 제거한 뒤 시즌별 20경기 조건을 그대로 적용합니다. 연구범위 최고Elo는11명에게 확보했습니다.

홍콩오픈·독일오픈 공식 역대 여자단식 우승자PDF에서15명의37개 대회별 우승 연도를 정리했습니다. 서로 다른 시대/등급의 투어 우승을 합산해 GOAT 점수에 넣지 않습니다. 1980–1990년대 은퇴4명의 경기별 표본과2009년 이전 정확한 주별1위 기간은 이 원자료의 범위 밖입니다. 우승 사실·랭킹 단일 관측값과 전체 경력 시계열을 구분합니다.

정적 실행과 빌드는 Node만 필요합니다. 원본 재추출 시에만 Python3와 openpyxl이 필요합니다.

```sh
python -m pip install openpyxl
python scripts/import-research-data.py
npm run data:rankings
npm run data:build
npm test
npm run build
```

원본 XLSX/전체 CSV는 `.research/`에만 보관합니다. 저작자표시·변경·데이터 조건은 `public/licenses/harvard-attribution.txt`, 랭킹 데이터 MIT 고지는 `public/licenses/sanderp99-mit.txt`에 있습니다. 원자료는 고정 버전이며 새 연구판과 최신 랭킹 확인값을 자동 추정하지 않습니다.

전영오픈 전체 여자단식 우승 연도도 박물관 명단과 대조했습니다. 야마구치의 2024 공통 기준 수치를 2회에서 1회(2022)로 바로잡았으며, data/all-england-years.json과 수치가 일치하지 않으면 데이터 빌드가 실패하도록 검증합니다.

최종 검증: 단위 테스트35개·PC/모바일브라우저 테스트24개 통과, TypeScript/Vite빌드 성공. 원자료 병합본을 기준으로 검증했습니다.
